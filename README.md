# 曦界 Dawnlands · 手机网页版

**游玩地址：https://yjj0339.github.io/dawnlands-mobile/**

这是现有 Dawnlands 3.0.2 的独立浏览器适配版，保留采集、自由搭建、生产物流、居民经营、科技、区域探索及 89 章旅程的数据与系统。它使用 Godot 4.4.1 / WebGL 2，适合在支持 WebGL 2 的现代浏览器中横屏游玩。

## 操作

- 左侧摇杆移动；右侧空白区域拖动视角。
- 靠近树木或岩石，面向目标，长按「采集」，完成后松手。一次长按只采集一个目标。
- 「建造」中点选建筑，查看材料后开始放置，再用「旋转」「放置」确定位置。
- 「手册」查看成长目标、制作、生产物流和居民服务；「科技」消耗研究点，也提供实践研究。
- 「背包」查看资源与工具，「地图」查看世界。功能窗口可滑动；右上角返回世界。
- 「更多」中可以保存、下载存档备份、回基地、切换视角、切换视距和尝试全屏。

新世界从正常开局资源开始，没有注入测试资源。前期先完成采集，建设核心和太阳能，再发展伐木、加工与居民生活。没有怪物或战斗 Boss。

## 存档与加载

手机世界存于当前浏览器的 IndexedDB，和电脑版存档独立。清除网站数据、使用无痕浏览或更换浏览器可能失去本地进度；请用「更多 → 下载存档备份」保留副本。

首次需要下载约 123 MiB 世界资源，另加引擎和页面资源，建议使用 Wi-Fi。完整下载后会缓存资源，缓存保留时可以再次离线进入。系统清理缓存后需要重新下载。页面不会自动上传你的世界。

默认较近视距、30 帧上限；可在「更多」切换较远视距。网页版贴图与地形细分为手机做了调整，电脑版资源和存档不受影响。不同手机的实际帧率和内存能力不同，尚未覆盖实体手机测试；不保证所有手机都能流畅运行。

## 发布与许可

本仓库保存 GitHub Pages 可直接部署的网页产物。每个资源文件小于 GitHub 的单文件限制；世界资源分块压缩并校验 SHA-256。不是联网多人服务器。

引擎、字体与部分模型来自第三方：Godot、Noto、pixiv / VRoid 样本和 Quaternius 动画。具体授权、使用限制和归属见 [制作与素材说明](credits.html) 及 `licenses/`。不能把全部模型统一视为原创或 MIT 资产。

网页版本：`3.0.2-mobile.1`。后续可在此仓库更新页面产物，保留同源浏览器存档；更换域名不会自动迁移存档。
