# 曦界 Dawnlands · 手机网页版

**游玩地址：https://yjj0339.github.io/dawnlands-mobile/**

这是现有 Dawnlands 3.0.2 的独立浏览器适配版，保留采集、自由搭建、生产物流、居民经营、科技、区域探索及 89 章旅程的数据与系统。它使用 Godot 4.4.1 / WebGL 2，适合在支持 WebGL 2 的现代浏览器中横屏游玩。

## 操作

- 左侧摇杆移动；右侧空白区域拖动视角。
- 靠近树木或岩石，面向目标，长按「采集」，完成后松手。一次长按只采集一个目标。
- 「建造」中点选建筑，查看材料后开始放置，再用「旋转」「放置」确定位置。
- 「手册」查看成长目标、制作、生产物流和居民服务；「科技」消耗研究点，也提供实践研究。
- 「背包」查看资源与工具，「地图」查看世界。功能窗口可滑动；右上角返回世界。
- 「更多」中可以保存、下载存档备份、回基地、切换视角和尝试全屏。
- 画质有「省电」「清晰」「高清」三档，实际调整画面分辨率；默认清晰。高清适合性能较好的手机。

新世界从正常开局资源开始，没有注入测试资源。前期先完成采集，建设核心和太阳能，再发展伐木、加工与居民生活。没有怪物或战斗 Boss。

## 存档与加载

手机世界存于当前浏览器的 IndexedDB，和电脑版存档独立。清除网站数据、使用无痕浏览或更换浏览器可能失去本地进度；请用「更多 → 下载存档备份」保留副本。

首次需要下载约 123 MiB 世界资源，另加引擎和页面资源，建议使用 Wi-Fi。先下载并初始化引擎，再按 34 个小块下载世界，各块会核对完整性。下载失败时显示具体阶段与「重新尝试」，不会一直等待。浏览器拒绝资源缓存时仍可联网游玩；缓存保留且资源下载完整时可以再次离线进入。页面不会自动上传你的世界。

默认较近视距、30 帧上限。清晰和高清模式取消原来的固定 75% 3D 渲染，并按高清屏像素增加画布分辨率；高清有 300 万像素预算，避免无限放大。网页版贴图与地形细分为手机做了调整，电脑版资源和存档不受影响。可直接在 Safari 打开；微信中如遇内置浏览器限制，可用菜单在 Safari 打开同一网址（两个浏览器的本地世界不互通）。

遇到问题可展开入口的「加载诊断」，它只显示本地加载状态，不上传存档。请先刷新网站，不要清除网站数据。自动测试包含实际引擎启动、触控、采集、建造、存档重进、断网启动，以及损坏引擎文件后重试、缓存被拒绝、旧浏览器解压回退。尚未覆盖实体 iPhone；Windows WebKit 渲染与触控回归存在异常，不能称为 iOS Safari 实机认证。

## 发布与许可

本仓库保存 GitHub Pages 可直接部署的网页产物。每个资源文件小于 GitHub 的单文件限制；世界资源分块压缩并校验 SHA-256。不是联网多人服务器。

引擎、字体与部分模型来自第三方：Godot、Noto、pixiv / VRoid 样本和 Quaternius 动画。具体授权、使用限制和归属见 [制作与素材说明](credits.html) 及 `licenses/`。不能把全部模型统一视为原创或 MIT 资产。

网页版本：`3.0.2-mobile.2`。后续可在此仓库更新页面产物，保留同源浏览器存档；更换域名不会自动迁移存档。
